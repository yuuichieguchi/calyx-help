Mission Map は、現在のウィンドウにあるターミナルペインをすべてカードにして、ウィンドウの上に並べます。
複数のタブでエージェントを動かしているとき、どれが処理中で、どれが自分の応答を待っていて、どれとどれがやり取りしているかを、タブを切り替えずに確かめられます。

## 開き方と閉じ方

次のどの方法でも開けます。

- `Cmd+Shift+M` を押します。ターミナルペインにフォーカスがあっても効きます。
- メニューバーの **View → Mission Map** を選びます。
- [コマンドパレット](/ja/usage/command-palette/)から **Mission Map** を実行します。
- タブバーまたはサイドバーのタブを右クリックし、**Show All Tabs** を選びます。
- Ghostty の `toggle_tab_overview` アクションに割り当てたキーを押します（[キーバインドアクション](/ja/usage/customization/#キーバインドアクション)を参照）。既定では何のキーも割り当てられていません。

マップはサイドバーとタブバーを含むウィンドウ全体を覆い、カードが収まらないときは縦にスクロールします。
マップはウィンドウごとに独立していて、そのウィンドウのペインだけを表示します。

閉じるには、右下の「esc to close」の表示どおり `Esc` を押します。
カードか線を選択しているときは、一度目の `Esc` で選択が外れ、二度目でマップが閉じます。
もう一度 `Cmd+Shift+M` を押すか、コマンドパレットかコンポーズオーバーレイを開いても閉じます。
何もない場所をクリックしても選択が外れるだけなので、うっかりクリックしてマップが閉じることはありません。

## カード

ウィンドウ内のすべてのタブの、すべてのスプリットペインがカードになります。
カードはタブグループごとの帯にまとめられ、帯の見出しにグループ名が出ます。
ブラウザタブと diff タブにはカードがありません。

カードには次の情報が表示されます。

- [エージェントサイドバー](/ja/usage/ai-agents/#エージェントサイドバー)と同じ色のステータスドット。赤 (ユーザー入力待ち)、黄 (処理中)、緑 (待機)、青 (完了) の四色です。
- エージェント名（Claude Code、Codex など）と、未読の AI Agent IPC メッセージの件数バッジ。
- ペインのタイトルと作業ディレクトリ。
- 作業ディレクトリが Git リポジトリの中にあるときは、ブランチ名（ブランチをチェックアウトしていないときはコミットの短いハッシュ）と、変更があればその変更ファイル数。この行はマップを開いている間、5 秒ごとに更新されます。
- エージェントがいま実行しているツール。
- 実行中のサブエージェントごとに一行。ステータスドットと、実行中のツール（ツールを実行していなければその状態）が出ます。

エージェントが動いていないペインは **Terminal** と表示され、ドットが中抜きになり、カード全体が薄く表示されます。
herdr がホストしているエージェントも、この表示になります（[既知の制約](/ja/reference/known-limitations/#mission-map-での-herdr-のエージェント)を参照）。

## カード上の承認

ペインに保留中の[承認リクエスト](/ja/usage/ai-agents/#エージェントのツール実行承認)があると、そのカードにオレンジ色の **Waiting for approval** の行が加わり、枠がオレンジ色に点滅します（「視差効果を減らす」がオンのときは点滅しません）。
保留中のリクエストが複数あるときは、いちばん古いものを表示します。

ツールの実行許可を求めるリクエストでは、**Allow** を押すとマップを離れずに承認できます。
**Open** を押すとマップが閉じ、承認パネルにそのリクエストが表示されます。
ほかの選択肢（**Options** メニューと **No**）はそちらにあります。
エージェントからの質問と、[MCP App](/ja/usage/mcp-apps/) の同意プロンプトには **Open** だけが出ます。

## ペイン同士を結ぶ線

エージェント同士が [AI Agent IPC](/ja/usage/ai-agents/#ai-agent-ipc) でメッセージを送ると、送信元のカードと受信先のカードが線で結ばれます。
線の上を、メッセージ一件につき一つのドットが送信元から受信先へ流れます（新しいものから八件まで）。
同じ二つのペインの間で同じ向きに送られたメッセージは一本の線にまとまり、逆向きのメッセージはその隣を並走する別の線になります。
ブロードキャストは、送信元から、ウィンドウ内でエージェントがピアとして登録済みのほかのすべてのペインへ線を引きます。
線はカードを避けて直角に折れ曲がります。

線は最新のメッセージから 10 秒間はくっきり表示され、そのあと薄くなり、そのメッセージから 2 分後に消えます。
Calyx はメッセージを送信の時点で記録しているので、あとからマップを開いても直近 2 分間のやり取りが表示されます。
別のウィンドウのペインとの間のメッセージには線が引かれません。

二つのペインのエージェントが直近 5 分以内に同じファイルを編集すると、その二つのカードがファイル名付きの赤い線で結ばれます。
二つのエージェントが同じファイルに手を入れていることに、この線で気付けます。
Calyx は、エージェントが報告するファイル書き込み系のツール呼び出し（Claude Code の Write や Edit、Codex の `apply_patch` など）から編集を把握します。
ファイルを読んだだけでは対象になりません。
メッセージの線と違い、赤い線は薄くなりません。

### 線の内容を読む

線をクリックすると、その線が選択され、横にポップオーバーが開きます。

- メッセージが一件の線では、**Message** または **Broadcast** という題でその本文を表示します。
- メッセージが複数の線では、新しい順に一覧し、それぞれに送信からの経過時間を添えます。表示は八件までで、残りは「+N more」とまとめられます。
- 赤い線では、両方のエージェントが編集したファイルのパスを表示します。

ポップオーバーの中をクリックしても閉じません。
閉じるには、ポップオーバーの **×** ボタンを押すか、`Esc` を押すか、何もない場所かカードをクリックします。
別の線をクリックするとポップオーバーはその線に移り、線が消えたときにもポップオーバーは閉じます。

## ペインを選択して開く

カードをクリックすると選択されます。
選択できるのは一度にカードか線のどちらか一つだけで、片方を選ぶともう片方の選択は外れます。

カードをダブルクリックするか、右上の開くボタンを押すと、マップが閉じてそのペインに移動します。
Calyx はそのペインのタブに切り替え、ほかのスプリットが拡大されていれば元に戻し、そのペインにキーボードフォーカスを移します。

## カードの配置

カードはドラッグで動かせます。
ドラッグ中も、線はカードに付いて動き、カードを避けるように引き直されます。

Calyx は動かしたカードの位置を覚えていて、ウィンドウのレイアウトと一緒に保存します。
そのため、マップを閉じても、[セッションの自動復元](/ja/usage/tabs-and-splits/#セッションの自動復元)で Calyx を再起動しても、配置はそのまま残ります。
位置はカードが自動で置かれる場所からのずれとして記録されるので、ウィンドウの大きさを変えたりペインを増減したりすると、動かしたカードもレイアウトに合わせて移動します。
配置をリセットするコマンドはありません。
ペインを閉じると、そのカードの位置は破棄されます。
